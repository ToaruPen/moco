# Codex Runtime Contract Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 実行時 Codex の生成 schema で Realtime v3/audio/WebRTC と approval response を開始前に検証し、ChatGPT.app 同梱版で moco のブラウザ会話を起動できるようにする。

**Architecture:** 既存の `CodexProtocolContract` に Realtime start semantic を追加し、production payload 全体を invocation witness として検証する。Capability discovery と Voice session は同じ contract を使い、legacy approval の追加値は送信しない schema variant としてだけ認識する。バージョン文字列分岐、v2 fallback、新しい negotiation layer は追加しない。

**Tech Stack:** Python 3.13、asyncio、JSON Schema generated by Codex app-server、pytest/pytest-asyncio、FastAPI/WebSocket、launchd

---

    variants = [
        decision_string("approved"),
        decision_object("approved_execpolicy_amendment", "proposed_execpolicy_amendment"),
        decision_string("approved_for_session"),
        *(
            [decision_string("approved_mcp_policy_amendment")]

        ),

        refusal,
        decision_string("timed_out"),

    ]
    return {"oneOf": variants}
